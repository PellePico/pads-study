# PADS study site

An interactive study site for *Programming, Algorithms and Data Structures* (Python), built while revising for the exam.

**▶ Open it: [pellepico.github.io/pads-study](https://pellepico.github.io/pads-study/)**

- **Six subjects:** Python foundations · Working with data · Classes (OOP) · Algorithms & data structures · NumPy, Pandas & plots · Exam practice
- **Step through code** line by line, with variables, the call stack and drawings
- **Interactive widgets** (slicing ruler, inheritance lookup, DFS/BFS explorer, `axis=` grid, …)
- **Try it** boxes that run real Python in the browser (Pyodide), plus exam-style quizzes

Plain HTML, CSS and JavaScript, with no build step. Open `index.html` locally or use the link above.
